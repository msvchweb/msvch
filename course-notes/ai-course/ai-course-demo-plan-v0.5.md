# AI 활용 강의 진행안 v0.5

2026-10-28 · 시연 중심 개정

## 진행 방식

강사가 실제 앱을 조작하며 가르친다. 긴 설명 슬라이드를 넘기는 흐름을 줄이고, 짧은 활용 사례를 바꿔가며 결과를 보여준다. 기능은 사용하는 순간에 설명한다. 수강생에게 보여줄 것은 실제 앱·입력자료·완성 결과이며, 자세한 순서와 요청문은 강사용 시나리오에 둔다.

한 강의는 여러 번의 수업에 나누어 진행할 수 있다. 전체 과정은 12강이며 GitHub·Vercel을 통한 자기 앱 제작·관리는 9강부터 진행한다. 1강의 Sites는 간단한 앱 생성·수정 맛보기다.

## 1강

[1강 시연 시나리오](ai-course-lesson-1-demo-script-v0.1.md)를 현재 진행안으로 사용한다.

후킹 → Pixel Agents 등 결과 사례 → 앱 설치·가입 → 프로젝트 → 로컬·클라우드 → Work 문서·표·발표·이미지 → 예약 → 플러그인 → 스킬 맛보기 → Sites → 예약 결과·개인 적용 순서다.

가상 모임 하나를 모든 기능에 반복 적용하지 않는다. 메모 정리·생활비·자기소개·독서 모임·영어 복습·여행 준비·집중 타이머로 상황을 바꾼다.

## 후속 강의의 구성 기준

| 강 | 시연을 시작할 장면 | 직접 해볼 일 |
|---|---|---|
| 2 | 같은 요청을 보내도 내 작성 기준이 적용되는 두 결과 | 프로젝트 지침을 넣고 새 대화에서 적용 |
| 3 | 폴더 안의 자료가 새 결과 파일로 바뀌는 장면 | 로컬 폴더에서 읽기·만들기·수정 |
| 4 | Drive·메일 원문을 찾아 바로 정리한 결과 | 연결 도구로 지정 자료 검색·활용 |
| 5 | 저장한 작성 방식으로 다른 자료도 정리하는 장면 | 내 양식을 스킬로 만들고 재사용 |
| 6 | 예약한 작업의 실제 실행 결과 | 작은 예약을 시험하고 수정·중지 |
| 7 | 휴대폰 요청으로 컴퓨터의 작업이 이어지는 장면 | 연결된 기기에서 기존 작업 이어가기 |
| 8 | 각자의 공부·발표·생활·업무 결과 | 필요한 기능을 골라 자기 작업 완성 |

각 강의는 결과 먼저 → 조작 시연 → 짧은 요청 → 결과 확인 → 직접 해보기로 진행한다. 필요한 주의사항은 해당 동작에서 짚고, 같은 설명을 매번 반복하지 않는다. 예제 수는 진행 속도에 맞추며 주제와 관련 없는 도구를 추가하지 않는다.

## 반영 상태

이번 개정은 강사용 진행안과 1강 시나리오에 반영했다. 기존 웹 슬라이드와 자료는 보관하며, 기능 시연용 슬라이드를 새로 만들거나 운영 사이트를 배포하지 않는다. v0.4의 1강 24장 진행안 대신 이 문서와 새 시나리오를 사용한다. 다른 강의의 세부 시나리오는 해당 강의 준비 때 같은 기준으로 작성한다.

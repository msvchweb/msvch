이 폴더는 로컬의 Git 제외 폴더 `docs/`에 있던 강의안 여섯 개를 보존한다. 이후 편집은 **이 추적되는 폴더**에서 한다. 예전 v0.2·v0.3·최초 강의안은 역사 자료다. 최신 사용자 지시와 v0.5·시연 시나리오를 우선한다.

## 사용자가 원하는 수업

- 교회에서 진행하는 AI 활용 과정. 학생·직장인 등 여러 배경의 수강생이 있다. 특정 직업이나 학생 신분을 촌스럽게 열거하는 홍보 문구를 쓰지 않는다.
- 전체 12강. ‘1주차·2주차’ 대신 **1강·2강**을 쓴다. 한 강의가 여러 번의 수업에 걸쳐도 된다. 1강을 한 시간에 억지로 끝내지 않는다.
- 장황한 설명, 멋있는 척하는 문장, 빽빽한 글과 반복 주의사항을 싫어한다. 짧고 평범한 한국어로, 바로 쓸 수 있는 기능을 보여준다.
- **최신 방향은 강사 직접 시연 중심**이다. 기능 설명용 슬라이드를 더 만들지 않는다. 활용법마다 공부·발표·생활·업무의 짧은 사례를 바꾼다. 공통 모임 사례 하나를 계속 반복하지 않는다.
- 1강 순서: ‘파일 끌어 넣고 질문만 했다면’ 후킹 → Pixel Agents 같은 활용 장면 → ChatGPT 데스크톱 설치·가입 → 프로젝트 → 로컬·클라우드 → Work 문서·표·발표·이미지 → 예약 → 플러그인 → 스킬 맛보기 → Sites → 예약 결과·개인 적용.
- ‘ChatGPT의 10%만 쓰고 있었다’는 도입 비유다. 측정된 통계로 주장하지 않는다. Pixel Agents는 Claude Code 기반 별도 사례이며 ChatGPT 기본 기능으로 소개하지 않는다.
- GitHub·Vercel 가입·연동, 자기 앱을 만들고 수정·배포하는 과정은 9강부터. 1강 Sites는 간단한 타이머 앱 생성·수정 시연이다.

## 현재 만들어진 것

- 홍보 `/ai-course`, 강의 선택 `/ai-course/lessons`, 기존 발표 `/ai-course/week-1`~`week-8`.
- 수강생에게 보이는 단위는 강으로 변경했다. 기존 `week-N` URL과 내부 `week` 필드는 북마크 호환을 위해 유지한다.
- 웹 슬라이드는 1강24장, 2~7강 각각13장, 8강15장으로 총117장이다. 방향키·이전/다음·슬라이드 선택·해시 재개·전체화면·모션 제어가 있다. 8강 첫 제목은 주황색 `#f97316`.
- 기존 웹 슬라이드는 보관 중이다. 최신 시연 중심 개정은 강사 Markdown 진행안에 반영했다. 시나리오 변경을 슬라이드에 자동으로 옮기거나 삭제하지 않는다.
- 실습 입력은 `public/ai-course/lesson-1/materials/`, 후속 공통 자료는 `public/ai-course/materials/`. ZIP도 함께 있다. 인물·행사·주소는 가상이다.
- 새 시연안에는 생활비 CSV·가상 여행 메모·요청문이 포함되어 있다. 실제 Pixel Agents 실행·PPT·포스터·타이머 생성과 강사 계정 연결 리허설은 아직 준비할 일이다. 문서를 작성했다는 이유로 이미 실행한 결과라고 말하지 않는다.
- 마지막 기능 커밋은 `a6d814d`. 이 인수인계 이후의 커밋은 강의 문서 보존용이다. 해당 기능 변경을 운영 배포하지 않았다. 원래 운영 사이트에는 더 오래된 내용이 있을 수 있다.
- 신청 기능은 기존 DB 패턴을 사용한다. 사용자가 확정한 개인정보 보관기간은 강의 종료 후3개월이다. 이번 이전 작업에서 DB·신청 기능은 변경하지 않는다.

## 클라우드에서 시작하기

브랜치 `codex/ai-course-week-one`을 체크아웃하고 현재 SHA를 확인한다. 기본 main으로 시작했다면 이 브랜치를 가져와 이동한다. 다른 작업자의 변경이 있으면 덮어쓰지 않는다.

```bash
npm ci
npm run test -- src/components/ai-course/lesson/first-lesson.test.tsx src/components/ai-course/lesson/course.test.tsx src/components/ai-course/lesson/course-route.test.tsx
npm run dev -- --hostname 0.0.0.0 --port 3000 --webpack
```

Node.js22 LTS 또는 설치된 Next.js16의 요구 버전(20.9 이상)을 사용한다. 웹 미리보기가 필요할 때만 개발 서버를 시작한다. 이전 Windows 환경에서는 Turbopack 개발 서버가404를 반환해 webpack으로 검증했다. 클라우드의 localhost는 원래 PC의 `127.0.0.1:3112`와 다르다.

이전 검증: 관련9파일66테스트, 프로덕션 빌드, PC117장·모바일 새1강24장, 해시 재개·다운로드 검증을 통과했다. 마지막 문구 수정 후 관련3파일21테스트도 통과했다. 이는 로컬 검증 기록이며 클라우드 실행 결과는 따로 확인한다.

로컬 `.env.local`, 브라우저 로그인, 플러그인 인증, 개인 설정은 이 Git 이전에 포함하지 않는다. 강의 자료·순수 슬라이드 테스트에 운영 DB·메일·배포 자격증명을 추가하지 않는다. 실제 연동이나 전체 앱 실행이 필요해지면 별도 개발용 설정을 확인한다.

## 새 채팅의 첫 작업

이 폴더와 현재 브랜치를 읽고 최신 결정·파일이 보존되었는지 확인한다. 관련 테스트 실행 결과와 준비 상태만 짧게 보고한다. 이후 사용자의 다음 지시를 기다린다. 아직 지시하지 않은 강의 개편, 예제 앱 제작, 플러그인 설치, DB 수정, main 병합, 운영 배포를 시작하지 않는다.

사용자는 이 클라우드 채팅 생성과 자료 인계를 승인했다. 이 승인으로 원래 채팅을 보관 처리하거나 로컬 작업 폴더를 삭제하지 않는다.

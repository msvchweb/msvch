# 1강 시연 시나리오 — 파일만 올려 쓰고 있었다면

2026-10-28 · 강사용 진행안 v0.1

슬라이드 대신 앱 화면을 띄우고 진행한다. 짧은 사례를 바꿔가며 **결과 보여주기 → 직접 조작 → 요청문 입력 → 결과 열기**를 반복한다. 한 번의 수업에 다 끝낼 필요는 없다. 아래 번호 중 멈춘 곳부터 다음 수업에 이어간다.

## 진행 순서

| 순서 | 보여줄 것 | 핵심 장면 |
|---|---|---|
| 0 | 도입 | “나, ChatGPT 10%만 쓰고 있었네” |
| 1 | 활용 사례 세 장면 | Pixel Agents → 완성된 발표자료 → 움직이는 타이머 앱 |
| 2 | 데스크톱 앱 설치·회원가입 | 공식 다운로드 → 앱 실행 → 로그인 또는 가입 |
| 3 | 프로젝트 생성 | 프로젝트 하나에 서로 다른 작업 대화 담기 |
| 4 | 로컬·클라우드 | 첨부 자료를 쓰는 작업과 컴퓨터 폴더를 쓰는 작업 비교 |
| 5 | Work: 메모 → Word | 메모 이미지가 편집할 문서로 바뀌는 장면 |
| 6 | Work: 지출 → Excel | 지출 목록이 합계와 차트가 있는 표로 바뀌는 장면 |
| 7 | Work: 자기소개 → 발표자료 | 짧은 소개로 PPT 만들고 한 장 수정하기 |
| 8 | Work: 문구 → 이미지 | 독서 모임 포스터 만들고 날짜 확인하기 |
| 9 | 예약 | 한 번 시험 예약하고, 다른 시연 뒤 실행 결과 확인 |
| 10 | 플러그인 | Drive 자료를 찾아 가져오는 장면 |
| 11 | 스킬 맛보기 | 방금 쓴 작업 방식을 다음에도 부르는 방법 |
| 12 | Sites | 타이머 앱 생성 → 직접 클릭 → 말로 수정 |
| 13 | 마무리 | 예약 결과 열기 → 각자 쓸 기능 하나 실행 |

## 0. 첫 말

> ChatGPT에 파일 끌어다 넣고, “요약해줘” 하고 쓰셨나요?
> 오늘 보시면 “나, 그동안 ChatGPT의 10%만 쓰고 있었네” 싶으실 겁니다.
> 먼저 화면 세 개만 볼게요.

곧바로 사례 화면을 연다. 학습 목표나 기능 목록을 먼저 설명하지 않는다.

강사용 메모: ‘10%’는 체감에 대한 비유다. 실제 이용률을 측정한 통계처럼 제시하지 않는다.

## 1. 먼저 보여줄 세 장면

1. **Pixel Agents — 30~45초.** 캐릭터가 일하는 화면과 실제 작업 내역을 함께 보여준다. “AI가 자료를 찾고, 만들고 있는 과정을 이렇게 보여주는 도구도 있습니다.”
2. **발표자료 — 15초.** 강사가 실제로 생성해 둔 PPT를 열고 두 장만 넘긴다. “이건 소개 몇 줄로 만든 발표자료예요. 오늘 직접 만들어보겠습니다.”
3. **타이머 앱 — 15초.** 시작·일시정지를 누른다. “이것도 원하는 기능을 말해서 만든 겁니다. 마지막에 만들어볼게요.”

Pixel Agents는 [Claude Code 기반 별도 도구](https://github.com/pixel-agents-hq/pixel-agents)다. ChatGPT 기본 기능으로 소개하지 않는다. 강사 환경의 실제 실행 화면이나 사전 녹화를 사용하고, 설치 설명은 이 자리에서 하지 않는다. 녹화라면 재생 전에 밝힌다.

## 2. 앱 설치 → 회원가입·로그인

**화면:** [공식 다운로드 페이지](https://chatgpt.com/download/) → 설치된 ChatGPT 앱.

**조작:** 운영체제에 맞는 설치 파일을 받아 실행한다. 계정이 있으면 로그인하고, 없으면 가입 화면에서 본인이 가입·인증을 완료한다. 설치가 끝난 사람은 앱을 열어 기다린다.

**말:** “계정이 있으면 그대로 로그인하세요. 새 계정을 또 만들 필요는 없습니다.”

앱에 로그인된 화면까지 확인하고 다음으로 간다. 긴 다운로드가 생기면 강사 시연을 먼저 보게 하고 설치는 지원 시간에 이어간다.

## 3. 프로젝트 하나 만들기

**화면:** Projects → 새 프로젝트 생성.

**조작:** 이름을 `내 AI 실습`으로 정한다. 그 안에서 `회의록`, `생활비`, `발표`처럼 결과별로 대화를 나누어 시작하는 위치를 보여준다. 프로젝트 지침을 쓰는 화면도 연다.

**말:** “관련된 자료와 대화를 여기 모아두면 됩니다. 작업마다 대화는 따로 열게요.”

지침은 두 줄만 넣는다.

```text
한국어로 짧게 답해줘.
파일을 만들어 달라고 하면 설명보다 완성 파일을 먼저 보여줘.
```

## 4. 로컬과 클라우드 — 화면 두 개로 설명

**조작:** 첨부 파일을 사용하는 클라우드 작업을 보여준 다음, 로컬 프로젝트에서 연습 폴더를 연결한다. 데스크톱 앱의 프로젝트 메뉴 → Edit project → Add folder로 폴더를 추가하는 방법을 보여준다.

**말:** “클라우드는 업로드하거나 연결한 자료로 작업합니다. 로컬 작업은 허용한 내 컴퓨터 폴더의 파일을 읽고 새 파일을 저장할 수 있어요. 지금 어느 자료를 쓰는지 여기서 보면 됩니다.”

로컬 프로젝트에서 입력한다.

```text
이 연습 폴더에 어떤 파일이 있는지 보여줘.
```

탐색기 목록과 답변을 나란히 본다. 다음 시연의 새 결과 파일이 같은 폴더에 생기는 장면까지 연결한다.

강사용 메모: 로컬도 AI 응답에 인터넷과 서비스가 필요하다. 클라우드 동기화와 컴퓨터 폴더 접근은 별개다. 동기화가 켜진 환경은 클라우드가 작업을 조율하고 연결된 컴퓨터가 로컬 작업을 실행할 수 있다. 수업 계정에서 실제 표시되는 실행 위치를 보여주고, 로컬을 ‘인터넷 없이 내 PC에서만 AI가 계산하는 방식’으로 설명하지 않는다.

## 5. Work — 메모 사진을 Word로

**화면:** 준비한 메모 이미지 → Work 선택 → 만들어진 Word 문서.

**말:** “사진 속 내용을 읽는 데서 끝내지 말고, 바로 나눠줄 문서로 받아볼게요.”

```text
이 메모로 회의록을 만들어줘.
할 일·담당자·기한은 표로 정리하고, 없는 정보는 ‘미정’으로 남겨줘.
편집할 수 있는 Word 파일로 만들어줘.
```

결과 파일을 직접 연다. 담당자와 날짜 한 항목을 메모와 대조한다. 이어서 “안내문만 세 문장으로 줄여줘”라고 수정한다. 로컬 작업이면 새 파일이 저장된 폴더도 연다.

메모는 기존 `public/ai-course/lesson-1/materials/meeting-note.png`를 사용할 수 있다. 다음 사례부터는 다른 상황으로 전환한다.

## 6. Work — 생활비를 Excel과 차트로

**화면:** 부록의 지출 다섯 줄 → Work 결과 Excel.

**말:** “이번엔 생활비입니다. 어디에 얼마나 썼는지 표와 차트로 받아볼게요.”

```text
이 지출을 분류별로 합쳐줘.
총합과 분류별 막대차트가 있는 Excel 파일로 만들어줘.
```

Excel 파일을 열어 합계 `29,900원`, 식비 `21,000원`을 짚는다. 숫자를 직접 바꾸고 합계가 갱신되는지 본다. 갱신되지 않으면 “금액을 바꾸면 합계와 차트도 바뀌게 수정해줘”라고 요청한다.

## 7. Work — 소개 몇 줄로 발표자료 만들기

**화면:** 짧은 가상 자기소개 → PPT → 수정된 한 장.

```text
민서는 사진 찍기와 산책을 좋아하고, 요즘 영어 회화를 배우고 있어.
처음 만난 사람들에게 소개할 발표자료 5장을 만들어줘.
큰 글씨와 밝은 색을 쓰고, 한 장에 내용 하나씩 넣어줘.
편집할 수 있는 PPT로 줘.
```

두 장만 넘겨본다. “두 번째 장은 글을 줄이고 사진이 크게 들어갈 자리로 바꿔줘”라고 요청한다. 수정된 장을 다시 연다.

**말:** “일단 만들고, 마음에 안 드는 장만 이렇게 고치면 됩니다.”

## 8. Work — 모임 포스터 한 장 만들기

```text
가상의 독서 모임 포스터를 만들어줘.
제목 ‘한 권 같이 읽기’, 11월 21일 오후 3시, 장소 ‘배움방’.
따뜻한 주황색으로 만들고 제목과 날짜가 크게 보이게 해줘.
```

이미지가 나오면 제목과 날짜를 확대해 읽어본다. 잘못된 글자가 있으면 그 부분을 바로 수정 요청한다. 이 자리에서 디자인 이론을 설명하지 않는다.

## 9. 예약 — 지금 맡겨두고 잠시 뒤 결과 받기

먼저 아래 세 표현으로 복습 문제를 한 번 만들어본다.

```text
오늘 배운 표현으로 한국어 뜻을 보고 영어를 맞히는 문제 3개와 정답을 만들어줘.
Could you say that again? — 다시 말씀해 주시겠어요?
Let me check. — 확인해 볼게요.
I'll get back to you. — 확인하고 다시 알려드릴게요.
```

결과를 보고 이어서 요청한다.

```text
현재 시각에서 5분 뒤에 이 세 표현의 새 복습 문제 3개와 정답을 만들어줘.
한국 시간 기준으로 한 번만 실행하고 이 대화에 남겨줘.
```

**화면:** 등록된 실행 시각과 작업 내용 → Scheduled의 상태.

**말:** “예약해둘게요. 다른 기능을 보는 동안 실행되는지 마지막에 열어보겠습니다.”

로컬 파일을 쓰는 예약은 컴퓨터와 앱이 켜져 있어야 한다고 이때 한 문장으로 설명한다. 수업에서는 실제 예약 작업의 실행 위치를 확인한다. 단순 알림과 새 문제 생성 결과를 구분해 보여준다. 한 번 예약이 제공되지 않는 환경이라면 수업 전에 확인한 일정을 사용하고 시연 후 중지한다.

## 10. 플러그인 — 파일을 다시 올리지 않고 Drive에서 찾기

**화면:** Customize → Plugins → Google Drive → 연결된 실습 계정 → 원문.

**조작:** 플러그인을 찾고 설치·연결하는 위치를 보여준다. 인증은 계정 소유자가 직접 한다. 시연은 준비해 둔 실습 계정으로 이어간다. `@`로 사용할 도구를 지정한다.

```text
Google Drive에서 ‘여행준비_연습’을 찾아줘.
교통·숙소·준비물을 체크리스트로 정리하고 원문 링크도 붙여줘.
```

검색된 문서 제목과 링크를 열어 실제 자료인지 본다.

**말:** “연결해두면 필요한 자료를 찾아 쓰게 할 수 있어요. 파일을 매번 다시 올리는 일을 줄이는 겁니다.”

## 11. 스킬은 방금 한 작업으로 짧게

**말:** “이 형식을 다음에도 쓰고 싶으면 작업 방법을 저장할 수 있습니다. 그게 스킬입니다.”

```text
방금 사용한 회의록 작성 방식을 스킬로 만들어줘.
이번 모임의 이름과 날짜는 빼고, 표의 항목과 정리 순서를 남겨줘.
```

스킬 생성 기능을 선택하고, 저장된 위치를 연 뒤 다른 짧은 메모로 호출한다. ChatGPT에서는 제공되는 `@skill-creator`, Codex에서는 `$skill-creator`를 사용할 수 있다. 이 자리에서는 생성·호출만 보여주고 자세한 편집은 5강에서 다룬다.

## 12. Sites — 내가 쓸 타이머 앱 만들기

**화면:** Sites 선택 → 생성된 앱 미리보기 → 실제 버튼 동작.

```text
Sites로 공부나 작업할 때 쓸 집중 타이머 앱을 만들어줘.
25분 집중·5분 휴식, 시작·일시정지·초기화 버튼을 넣어줘.
큰 숫자와 남은 시간을 보여주는 움직이는 원을 넣고, 휴대폰에서도 잘 보이게 해줘.
먼저 미리보기로 보여줘.
```

시작 → 일시정지 → 다시 시작 → 초기화를 누른다. 이어서 요청한다.

```text
시간을 직접 바꿀 수 있게 해줘. 주황색 테마로 바꿔줘.
```

바뀐 미리보기에서 시간을 입력하고 다시 실행한다.

**말:** “내가 쓸 기능을 말하고, 써보고, 고치는 겁니다.”

이번에는 미리보기에서 직접 쓰는 데까지 보여준다. Sites의 저장·공유·게시가 별도 단계라는 점만 짚는다. GitHub·Vercel로 자기 앱을 관리·배포하는 수업은 9강부터 이어간다.

## 13. 마무리

Scheduled 또는 예약 대화로 돌아가 새 문제와 실제 실행 기록을 연다. 아직 실행 중이면 상태를 그대로 보여주고, 실패했다면 완료했다고 설명하지 않는다.

> 오늘 본 것 중 바로 쓸 것 하나를 골라서 해보세요.
> 파일 만들기, 예약, 자료 연결, 앱 만들기 중 하나면 됩니다.

수강생은 자기 작업 하나를 실행한다. 강사는 설치·계정·기능별로 막힌 곳을 돕는다. 다음에 이어갈 사람은 마지막 시나리오 번호와 작업 대화를 남긴다.

## 강사 준비 — 수업 전에 한 번만 확인

- 앱 설치 파일과 다운로드 페이지, 로그인한 시연 계정, 연습 폴더를 준비한다. Work·예약·Drive·스킬·Sites 제공 여부는 실제 수업 계정으로 확인한다. 특정 요금제에서 모두 무료라고 안내하지 않는다.
- Pixel Agents 시연, Word·Excel·PPT·포스터·타이머 앱을 미리 한 번 실행해 결과를 준비한다. 이 문서 작성만으로 결과물이나 외부 계정 연결이 준비된 것은 아니다. 생성 대기 중에는 준비한 결과를 열어 설명하고 완료 후 새 결과로 돌아온다.
- Drive에는 아래 가상 여행 메모를 `여행준비_연습`으로 저장해 둔다. 연결 설치·인증 화면은 보여주되 오래 걸리는 인증으로 수업 전체를 멈추지 않는다.
- 실제 개인 자료 대신 연습용 사본으로 시연한다. 파일 생성 후 원본과 결과를 한 항목씩 대조하는 습관은 실제 화면에서 보여준다.

### 복사해서 준비할 입력자료

`생활비.csv` — 아래 내용을 UTF-8 CSV로 저장한다.

```csv
날짜,분류,내용,금액
2026-11-01,교통,버스,2800
2026-11-01,식비,점심,9000
2026-11-02,간식,카페,4500
2026-11-02,교통,지하철,1600
2026-11-03,식비,저녁,12000
```

`여행준비_연습` — 실제 예약이 아닌 가상 자료다.

```text
1박 2일 연습 여행 준비
교통: 버스 시간 확인 필요. 아직 예매하지 않음.
숙소: 가상 숙소 A와 B 비교 중. 아직 예약하지 않음.
준비물: 충전기, 세면도구, 가벼운 겉옷.
함께 정할 것: 출발 시각과 식사 예산.
```

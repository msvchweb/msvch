# ChatGPT·Codex로 내 업무를 바꾸는 8주 실습 강의안

작성일: 2026-10-21  
문서 상태: 검토용 권장안 v0.1  
범위: 전체 12주 과정 중 1~8주. 홈페이지 제작은 9주차부터 시작한다.

## 1. 과정의 방향과 운영 조건

이 과정은 다양한 직업을 가진 교회 구성원이 ChatGPT와 Codex를 자신의 직장·사업·일상에 활용하도록 돕는 실습 과정이다. 수강생은 글쓰기와 검색에 AI를 사용한 경험이 있지만, 파일 작업·지침·플러그인·스킬·예약·원격 연결에는 익숙하지 않은 것으로 가정한다.

8주 동안 자료를 주고 결과를 받는 작업에서 출발해, 자신에게 맞는 작업 환경을 만들고 반복 업무를 관리하는 단계까지 나아간다. 이후 9~12주에는 배운 방법을 사용해 GitHub·Vercel을 연결하고 개인 홈페이지를 제작·수정·운영한다.

| 항목 | 운영 기준 |
|---|---|
| 대상 | 다양한 직업을 가진 일반 성도 |
| 인원 | 10명 이하 |
| 수업 | 주 1회, 회당 60분 |
| 개인 과제 | 매주 20~30분 |
| 기기 | 전원 개인 노트북, Windows·Mac 혼합 가능 |
| 계정 | 수강 기간 ChatGPT 유료 구독 필수 |
| 중심 도구 | ChatGPT와 Codex의 웹·데스크탑·모바일 환경 |
| Claude | 필요할 때 대응 기능을 짧게 비교. 별도 가입·유료 구독을 필수로 요구하지 않음 |
| 수업 방식 | 공통 자료로 함께 실습하고, 과제에서 자기 업무에 적용 |

| 확보한 시간 | 8주차 개인 업무 종합 실습에 배정 |

### 8주 후 수강생이 할 수 있어야 하는 일

1. 목적·자료·조건·완료 기준을 전달하고, 결과를 확인한 뒤 구체적으로 수정 요청한다.
2. 대화, 프로젝트, 지침, 메모리를 용도에 맞게 구분해서 사용한다.
3. 작업이 실행되는 곳과 파일이 저장되는 곳을 확인한다.
4. 필요한 플러그인과 외부 서비스를 연결하고 자료를 가져온다.
5. 반복하는 절차를 스킬로 정리해 다른 입력에도 재사용한다.
6. 검증한 작업을 예약하고 실행 기록·결과·중지 방법을 확인한다.
7. 모바일에서 연결된 컴퓨터의 작업을 시작하거나 이어간다.
8. 자기 업무 하나를 두 번 이상 재현할 수 있는 작업 절차로 완성한다.

## 2. 현재 제품 기준과 강의 적용 원칙

이 문서의 기능 검토 기준일은 2026-10-21이다. 현재 공식 문서는 데스크탑 앱에서 ChatGPT의 Chat·Work와 Codex를 선택하는 흐름으로 설명한다. 강의에서는 수강생에게 실제로 보이는 화면을 기준으로 안내하며, 대화·작업 실행·파일 접근의 차이를 설명한다. [공식 데스크탑 앱 안내](https://learn.chatgpt.com/docs/app)

기능은 요금제, 운영체제, 지역, 순차 배포, 계정·워크스페이스 설정에 따라 달라질 수 있다. 따라서 유료 구독만으로 모든 기능이 동일하게 제공된다고 안내하지 않는다. 강사는 개강 전 사용할 계정에서 핵심 실습을 직접 실행해 본다. [ChatGPT 활용 범위](https://learn.chatgpt.com/docs/use-chatgpt)

### 권장 계정·모델 운영

- 개인 수강생은 ChatGPT Plus를 기준 후보로 두고, 핵심 기능 접근과 실습 사용량을 확인한 뒤 모집 안내에 반영한다.
- 수업은 ChatGPT 계정 로그인 방식으로 구성한다. API 키 발급과 별도 API 과금은 필수 과정에 넣지 않는다.
- 첫 실행은 계정에 제공되는 기본 모델·기본 속도를 사용한다. 결과가 부족한 작업에서만 다른 모델이나 추론 설정을 비교한다.
- 모델 이름과 가격표를 암기시키기보다 작업의 복잡도, 결과 품질, 대기 시간, 사용량을 보고 선택하게 한다.
- 강사는 수업 전 사용량을 확인하고, 실습 파일의 크기와 반복 생성 횟수를 조정한다. 현재 공식 안내상 ChatGPT Work와 Codex는 사용량을 공유한다. [요금제와 사용량 안내](https://learn.chatgpt.com/docs/pricing)

### 세 가지를 구분해서 가르친다

| 구분 | 수강생에게 설명할 말 | 확인할 행동 |
|---|---|---|
| 작업 기준 | 지침은 계속 적용할 원칙이고, 스킬은 특정 업무를 수행하는 절차다. | 지침을 바꿨을 때와 스킬을 바꿨을 때 결과 차이 확인 |
| 실행 위치 | 클라우드·로컬은 작업 환경과 접근 가능한 파일을 구분하는 데 필요한 개념이다. | 지금 읽는 자료와 결과 파일의 위치 확인 |
| 실행 시점 | 지금 요청하는 작업, 예약된 작업, 모바일에서 이어가는 작업을 구분한다. | 실행 기록과 실제 결과를 열어 확인 |

플러그인은 스킬이나 외부 서비스 연결 도구 등을 묶어 제공할 수 있다. 플러그인과 스킬을 서로 완전히 별개인 기능으로 설명하지 않는다. [스킬·플러그인 안내](https://learn.chatgpt.com/docs/skills-and-plugins)

## 3. 공통 실습 시나리오와 자료

### 권장 공통 시나리오: 주간 업무 정리 도우미

회의 메모, 요청 사항, 진행 현황을 받아 다음 세 가지를 만든다.

1. 이번 주 핵심 상황 요약
2. 할 일·담당자·기한·확인 필요 사항을 정리한 실행 계획
3. 담당자에게 보낼 안내문 초안

첫 주에는 직접 자료를 첨부한다. 이후 프로젝트와 지침을 적용하고, 로컬 폴더나 연결된 서비스에서 자료를 읽고, 스킬로 반복 처리하고, 예약과 모바일까지 연결한다. 각 주에는 새로운 메모를 제공해 결과가 달라지는 것을 확인한다.

과제에서는 수강생이 자신의 업무로 바꾼다. 예를 들어 직장인은 회의 후속 업무, 자영업자는 고객 요청 정리, 프리랜서는 작업 진행 보고, 일반 생활에서는 모임 준비에 적용할 수 있다.

### 강사가 준비할 자료 구성

아래 목록은 제작할 교재의 명세다. 이 강의안 문서와 함께 실습 파일이 이미 생성된 것은 아니다.

| 자료 | 구성 | 활용 |
|---|---|---|
| 회의 메모 A | 1쪽 분량. 요청 5~7개, 담당·기한 누락 항목 포함 | 1~3주 기본 실습 |
| 업무 현황표 | 8~10행의 작은 CSV. 완료·진행·미정 상태 포함 | 파일 결합과 수치 확인 |
| 회의 메모 B | A 이후 변경 사항. 기한 변경과 취소 항목 포함 | 4~6주 반복 처리 |
| 검증용 메모 C | 누락 정보와 상충하는 요청을 의도적으로 포함 | 스킬·종합 실습 검증 |
| 결과물 예시 | 상황 요약, 실행 계획, 안내문 초안 각 1개 | 형식 비교와 검토 |
| 모바일 입력 자료 | 짧은 추가 메모와 글자가 선명한 메모 사진 | 7주 실습 |
| 개인 적용 기록지 | 입력 자료, 요청, 수정, 결과 확인, 소요 시간 | 매주 과제 |

모든 공통 자료는 가상 인물과 가상 업무로 구성한다. 실습은 개인별 자료 사본에서 진행한다.

### 권장 폴더 구조

```text
AI-실습/
  입력자료/
    회의메모-A.txt
    업무현황.csv
  결과물/
  참고자료/
    결과물-예시.md
  실습기록.md
```

Windows와 Mac 모두 같은 폴더 이름을 사용하고, 절대 경로는 각자의 실제 위치로 지정한다. 3주차부터 Codex에서 이 실습 폴더를 열어 사용한다.

## 4. 개강 전 준비와 수업 운영

### 수강생 준비 과제: 약 20~30분

- 사용할 ChatGPT 유료 계정으로 웹·데스크탑·모바일에 로그인한다.
- 노트북 앱과 모바일 앱을 업데이트한다.
- 실습 자료를 내려받고 파일 하나를 열어 본다.
- 4주차 연결 실습에 사용할 개인 Google 계정을 준비한다. 다른 서비스를 사용할 경우 강사가 제공하는 대체 실습을 따른다.
- 자신의 반복 업무 세 가지를 적고, 수업에 적용할 업무 하나를 고른다.

계정·기기 연결은 각자 본인의 화면에서 수행한다. 설치가 어려운 수강생에게는 Windows·Mac별 안내를 제공하고 첫 수업 전에 접속 여부를 확인한다.

### 강사 사전 점검

| 시점 | 준비할 일 |
|---|---|
| 개강 1주 전까지 | 두 운영체제의 설치 안내, 공통 자료, 결과물 예시, 대체 자료 준비 |
| 개강 2~3일 전 | 수강생별 로그인·유료 구독·핵심 메뉴 접근 확인 |
| 매주 수업 전 | 해당 주의 프롬프트를 처음부터 실행하고 결과·대기 시간 확인 |
| 4주차 전 | 연결할 플러그인의 실제 제공 기능과 인증 절차 확인 |
| 6주차 전 | 수업 중 시험 예약이 실행되는지 확인 |
| 7주차 전 | 모바일 원격 메뉴, 페어링, 노트북 연결 조건 확인 |

### 시간 운영 원칙

설명은 한 번에 5분 안팎으로 나누고, 설명 직후 수강생이 직접 조작한다. 매주 새로 도입하는 핵심 작업은 하나로 잡는다. 어려운 개념을 설명하느라 실습 시간을 소진하지 않도록 강사는 완성 예시와 복구용 자료를 준비한다.

한 수강생에게 발생한 계정 문제로 전체 실습이 멈추면, 해당 수강생은 준비된 파일로 결과 검토를 먼저 진행한다. 계정 연결이나 실제 예약 실행을 끝내지 못한 항목은 완료로 표시하지 않고 보완한다.

## 6. 1주차 — 자료를 주고 업무 하나 완성하기

### 학습 목표

수강생이 자료와 완료 기준을 제공하고, 결과를 확인한 뒤 후속 지시로 수정할 수 있다. 모델 선택과 파일 첨부는 실제 작업 중에 익힌다.

### 다룰 기능

새 대화, 모델 선택, 파일 첨부, 후속 질문, 결과 파일 확인·저장. 웹 검색과 이미지·음성 입력은 필요한 상황을 짧게 보여주고 별도 장시간 실습으로 늘리지 않는다.

### 60분 진행

| 시간 | 강사 진행 | 수강생 행동 |
|---|---|---|
| 0~5분 | 메모에서 실행 계획으로 바뀐 전후 사례 제시 | 자신이 줄이고 싶은 반복 업무 하나 선택 |
| 5~10분 | 목적·자료·조건·완료 기준을 담은 요청 시연. 모델 메뉴와 기본 선택 확인 | 실습 자료 열기 |
| 10~25분 | 파일 첨부 후 요청하는 과정을 지원 | 메모 A와 현황표로 실행 계획 생성 |
| 25~35분 | 담당·기한 누락과 자료 간 차이를 확인하는 방법 설명 | 원문과 비교해 오류 또는 확인 필요 사항 찾기 |
| 35~50분 | 후속 요청과 결과 저장 시연 | 우선순위를 조정하고 안내문 초안 생성·저장 |
| 50~60분 | 결과 2개를 함께 검토하고 과제 안내 | 처음 요청과 수정 요청의 차이 기록 |

### 핵심 실습 프롬프트

```text
첨부한 회의 메모와 업무 현황표를 바탕으로 이번 주 실행 계획을 만들어줘.
할 일, 담당자, 기한, 현재 상태, 근거 자료를 표로 정리해줘.
자료에 없는 담당자나 날짜는 추측하지 말고 ‘확인 필요’로 표시해줘.
두 자료의 내용이 다르면 차이를 따로 알려줘.
표 아래에는 내가 먼저 결정해야 할 사항을 세 가지 이내로 적어줘.
```

후속 요청 예시:

```text
내가 이번 주에 처리할 수 있는 일은 세 가지야.
우선순위를 제안하고 판단 근거를 적어줘.
확정된 내용만 사용해 담당자에게 보낼 안내문을 300자 이내로 작성해줘.
실제 발송은 하지 말고 초안으로 보여줘.
```

### 과제: 20~30분

자기 업무 메모로 같은 과정을 한 번 실행한다. 최초 요청, 수정 요청, 최종 결과, 직접 확인한 사실 두 가지를 기록한다.

### 완료 기준

- 원문에 없는 담당자·날짜를 사실처럼 채우지 않았는지 확인했다.
- 적어도 한 번 구체적인 수정 요청을 했다.
- 최종 결과물을 다시 열어볼 수 있는 위치에 저장했다.

### 강사 메모

AI의 답변 길이나 문장 표현보다 실제로 사용할 수 있는지에 집중한다. 파일을 처리하지 못하면 같은 내용의 텍스트 사본으로 실습을 이어간다. 결과가 그럴듯하더라도 원문 확인 단계를 건너뛰지 않는다.

## 7. 2주차 — 지침·메모리·프로젝트로 나에게 맞추기

### 학습 목표

매번 전달할 정보와 지속해서 적용할 기준을 구분한다. 프로젝트 안에서 서로 다른 대화를 시작해도 필요한 자료와 작성 기준을 찾을 수 있게 정리한다.

### 다룰 기능

개인 지침, 프로젝트 지침과 자료, 메모리의 확인·수정·삭제, 대화 이름 변경·검색·고정·보관. Codex의 프로젝트 지침 파일인 AGENTS.md는 강사가 개념만 연결하고 실제 파일 적용은 3주차에서 진행한다.

프로젝트는 관련 대화와 자료를 묶는 데 사용한다. 대화를 고정하는 것만으로 AI에게 추가 자료가 제공되는 것은 아니다. [프로젝트·대화 안내](https://learn.chatgpt.com/docs/projects)

### 60분 진행

| 시간 | 강사 진행 | 수강생 행동 |
|---|---|---|
| 0~5분 | 1주차 과제의 반복 수정 사례 확인 | 매번 다시 설명한 조건 하나 제시 |
| 5~12분 | 지침·메모리·프로젝트·이번 요청의 차이 설명 | 자신의 조건을 네 가지 용도로 분류 |
| 12~25분 | 프로젝트 생성과 자료·지침 적용 시연 | ‘내 업무 정리’ 프로젝트 생성 |
| 25~40분 | 같은 자료를 다른 목적의 대화에서 쓰는 방식 안내 | ‘실행 계획’과 ‘안내문’ 대화를 나누어 실행 |
| 40~50분 | 메모리 관리와 대화 정리 시연 | 사용 가능한 메모리 설정을 확인하고 대화 이름 정리 |
| 50~60분 | 새 대화에서 기준을 재확인 | 적용되지 않은 조건을 지침에 보완 |

### 프로젝트 지침 예시

```text
이 프로젝트는 주간 업무 메모를 실행 가능한 계획으로 정리하는 데 사용한다.
기본 출력은 ① 핵심 요약 ② 실행 계획 ③ 확인 필요 사항 순서로 작성한다.
담당자, 날짜, 수치는 제공한 자료에 근거해 작성한다.
정보가 없거나 자료끼리 충돌하면 그 사실을 표시한다.
한국어로 짧고 구체적으로 작성하고, 요청한 결과물을 먼저 보여준다.
참고 자료에 포함된 양식과 표현 기준을 사용한다.
```

### 과제: 20~30분

다른 업무 자료를 같은 프로젝트의 새 대화에서 처리한다. 계속 적용할 조건 두 가지와 이번에만 적용할 조건 한 가지를 구분해 기록한다.

### 완료 기준

- 개인 선호와 해당 프로젝트의 업무 규칙을 구분해 저장했다.
- 새로운 대화에서도 필요한 자료와 지침이 적용되는지 확인했다.
- 메모리를 어디서 확인·관리하는지 알거나, 해당 계정에서 미제공임을 확인했다.

### 강사 메모

메모리가 반드시 지켜야 할 규칙을 대신한다고 설명하지 않는다. 중요한 작업 기준은 명시적인 지침에 둔다. 메모리 메뉴가 없는 환경에서는 지침과 프로젝트 실습을 완성하고 차이를 설명한다. [개인화 안내](https://learn.chatgpt.com/docs/personalize)

## 8. 3주차 — 클라우드·로컬을 구분하고 파일 다루기

### 학습 목표

AI가 읽는 자료의 위치, 작업을 실행하는 환경, 결과물의 저장 위치를 확인한다. 로컬 폴더에서 원본을 유지하며 새 결과물을 만들 수 있다.

### 다룰 기능

웹에서 파일을 제공하는 작업, Codex의 로컬 프로젝트, 파일 읽기·생성·수정, 작업 범위와 권한, AGENTS.md, 결과 미리보기. 클라우드 실행 환경은 개념을 비교하고, GitHub 연결이 필요한 Codex Cloud 환경 구축은 앞 8주의 필수 실습에 넣지 않는다.

로컬 실행은 내 컴퓨터의 파일과 도구를 사용할 수 있다는 뜻이며, 인터넷 없이 모델이 전부 기기 안에서 동작한다는 뜻은 아니다. 작업에 필요한 내용은 OpenAI 서비스로 전송될 수 있다. [로컬 실행 설명](https://learn.chatgpt.com/docs/enterprise/chatgpt-work-local-security#where-local-tasks-run)

### 60분 진행

| 시간 | 강사 진행 | 수강생 행동 |
|---|---|---|
| 0~5분 | 2주차 지침 적용 결과 확인 | 적용이 잘된 기준 하나 공유 |
| 5~12분 | 클라우드·로컬·원격 연결의 차이를 자료 위치로 설명 | 현재 결과물이 있는 위치 확인 |
| 12~22분 | 실습 폴더를 로컬 프로젝트로 여는 과정 시연 | 자신의 실습 폴더 연결 |
| 22~32분 | 2주차 지침을 로컬 프로젝트에 적용하는 방법 설명 | AI에게 AGENTS.md 초안을 만들게 하고 내용 확인 |
| 32~50분 | 폴더 안 자료를 읽고 새 파일을 만드는 작업 지원 | 실행 계획과 안내문을 결과물 폴더에 저장 |
| 50~60분 | 결과 파일과 입력 자료를 함께 확인 | 파일을 앱 밖에서도 열고 저장 위치 기록 |

### 핵심 실습 프롬프트

```text
현재 프로젝트의 ‘입력자료’ 폴더에서 회의 메모와 업무 현황표를 읽어줘.
먼저 사용할 파일 목록을 알려줘.
프로젝트 지침에 따라 실행 계획과 안내문 초안을 작성해줘.
원본은 그대로 두고 ‘결과물’ 폴더에 서로 다른 이름의 Markdown 파일로 저장해줘.
완료 후 파일 위치와 확인이 필요한 내용을 알려줘.
```

AGENTS.md에 넣을 권장 범위: 이 프로젝트의 목적, 입력·출력 폴더, 결과 형식, 원본 유지, 누락 정보 처리. 개인 지침 전체를 무조건 복제하지 않고 해당 폴더에 필요한 내용만 옮긴다.

### 과제: 20~30분

새 메모 파일을 입력 폴더에 추가하고 같은 작업을 다시 실행한다. 입력 파일 목록, 생성된 파일 이름, 원본 유지 여부를 기록한다. 다음 주 사용할 Google Drive 실습 폴더에 자료 사본 두 개를 올려둔다.

### 완료 기준

- 작업이 어느 환경에서 실행되는지와 입력·결과 위치를 설명할 수 있다.
- 새 결과 파일을 직접 열었고 원본이 유지되었는지 확인했다.
- 프로젝트 지침 파일의 내용을 읽고 자신의 업무에 맞게 수정했다.

### 강사 메모

대화가 다른 기기에서 보이는 것과 로컬 폴더의 파일에 접근할 수 있는 것은 구분한다. 수강생에게 터미널 명령어 암기를 요구하지 않는다. AI가 실행하려는 작업의 목적과 범위를 읽게 한다. [프로젝트의 로컬 파일 접근](https://learn.chatgpt.com/docs/projects)

## 9. 4주차 — 플러그인과 외부 앱 연결하기

### 학습 목표

필요한 기능을 가진 플러그인을 찾고, 서비스 계정을 연결한 뒤 자료를 가져와 작업한다. 설치 완료와 계정 연결 완료를 구분한다.

### 다룰 기능

플러그인 탐색·설치, 포함된 스킬·연결 도구 확인, 계정 인증, 연결 상태, 자료 검색·읽기, 플러그인 비활성화 또는 연결 해제 위치.

주 실습은 Google Drive의 개인 실습 자료를 읽는 것으로 구성한다. 대체 서비스는 개강 전 실제 계정에서 동작을 확인한 파일 저장 서비스 하나만 선정한다. 특정 플러그인이 제공하지 않는 동작을 지원한다고 가정하지 않는다.

### 60분 진행

| 시간 | 강사 진행 | 수강생 행동 |
|---|---|---|
| 0~5분 | 준비된 Drive 자료와 로그인 확인 | 자신의 실습 폴더 확인 |
| 5~12분 | 플러그인·스킬·외부 앱 연결의 관계 설명 | 이번 업무에 필요한 연결 기능 식별 |
| 12~25분 | 설치·계정 연결·제공 기능 확인 시연 | 개인 계정 연결 완료 |
| 25~40분 | 서비스에서 파일을 찾고 읽는 작업 지원 | 자료 두 개를 찾아 실행 계획 생성 |
| 40~50분 | 근거 파일과 초안 결과 비교 | 문서 제목·링크·수정 시점 등 확인 가능한 정보 점검 |
| 50~60분 | 연결 관리와 실패 대응 안내 | 재실행 후 결과 저장, 연결 해제 위치 확인 |

### 핵심 실습 프롬프트

```text
연결된 Google Drive에서 내가 지정한 실습 폴더의 회의 메모 B와 업무 현황표를 찾아줘.
사용한 파일의 제목과 확인 가능한 링크를 먼저 알려줘.
파일을 읽은 뒤 이번 주 변경 사항과 확인이 필요한 사항을 정리해줘.
안내문은 초안으로 작성하고, 외부 공유나 발송은 하지 마.
지정한 파일에 접근할 수 없으면 필요한 정보를 알려줘.
```

### 과제: 20~30분

실습 폴더에 자료를 하나 추가한 뒤 다시 가져오도록 요청한다. 파일을 다시 첨부하는 작업과 연결된 서비스에서 가져오는 작업의 차이를 기록한다.

### 완료 기준

- 설치 상태와 연결 계정 상태를 각각 확인했다.
- 실제 외부 자료를 읽었는지 근거를 확인했다.
- AI가 찾은 파일이 자신의 의도와 맞는지 확인했다.

### 강사 메모

계정 인증은 개인별로 진행한다. 자료를 못 찾으면 파일 제목·위치·접근 권한을 확인하고, 필요하면 정확한 링크를 제공한다. 연결이 해결되지 않으면 내려받은 사본으로 결과 검토를 진행하되 외부 연결 실습은 보완 대상으로 남긴다.

여유가 있는 수강생에게만 읽기 결과를 문서로 저장하는 추가 실습을 준다. 지원되는 서비스의 쓰기 기능과 단순 파일 생성을 구분한다. [플러그인 개념과 연결](https://learn.chatgpt.com/docs/skills-and-plugins)

## 10. 5주차 — 반복 절차를 나만의 스킬로 만들기

### 학습 목표

반복해서 쓰는 작업 절차와 결과물 형식을 스킬로 만들고, 서로 다른 자료로 검증한다. 스킬을 만드는 것과 스킬이 제대로 동작하는 것을 구분한다.

### 다룰 기능

기존 스킬 사용, 스킬 제작 도우미, 명시적인 스킬 호출, 입력·출력 규칙, 참고 양식, 수정 후 재실행.

수업의 기본 제작 환경은 로컬 프로젝트를 사용할 수 있는 Codex로 잡는다. 공식 문서의 제작 도우미 호출 예시는 Codex의 $skill-creator이며, ChatGPT에서는 지원되는 화면의 @skill-creator를 사용한다. [스킬 사용·제작 안내](https://learn.chatgpt.com/docs/skills-and-plugins)

### 60분 진행

| 시간 | 강사 진행 | 수강생 행동 |
|---|---|---|
| 0~5분 | 지난 실습의 반복 요청 확인 | 계속 복사해 쓰는 지시를 표시 |
| 5~12분 | 설치된 스킬 하나를 시연하고 구성 설명 | 스킬 이름·목적·입력·출력 확인 |

| 38~50분 | 누락·충돌 자료로 검증하는 방법 안내 | 메모 C로 재실행하고 스킬 수정 |
| 50~60분 | 스킬 위치·호출·운영 기준 점검 | 사용할 때 제공해야 할 입력을 기록 |

### 스킬 제작 요청 예시

```text
주간 업무 정리 스킬을 만들어줘.
입력은 회의 메모와 업무 현황표야.
절차는 자료 확인, 변경 사항 파악, 실행 계획 작성, 안내문 초안 작성 순서야.
결과는 핵심 요약, 할 일 표, 확인 필요 사항, 안내문 순서로 만들어줘.
담당자와 기한이 없으면 추측하지 말고 표시해줘.
자료끼리 충돌하면 양쪽 근거를 적어줘.
수업에서 사용할 수 있도록 우선 지침과 참고 양식 중심으로 만들어줘.
초안을 만든 뒤 내가 준 두 자료로 시험하고 수정할 부분을 알려줘.
```

### 과제: 20~30분

개인 업무용으로 스킬의 이름·입력·출력을 바꾼다. 새로운 자료로 한 번 실행하고, 긴 지시를 다시 붙여넣지 않고도 필요한 결과가 나오는지 확인한다.

### 완료 기준

- 스킬의 목적과 필요한 입력을 한 문장으로 설명할 수 있다.
- 스킬을 다시 찾고 명시적으로 호출할 수 있다.
- 서로 다른 두 입력으로 실행했다.
- 누락 또는 충돌 상황에서의 처리 방식을 검증했다.

### 강사 메모

처음부터 많은 업무를 수행하는 범용 스킬을 만들지 않는다. 한 업무의 절차를 먼저 고정한다. 입력이 부족한 자동 실행에서는 임의로 채우지 않고 ‘확인 필요’ 결과를 남기도록 설계해 6주차와 연결한다.

## 11. 6주차 — 예약 작업을 만들고 실행을 관리하기

### 학습 목표

수동 실행으로 검증한 작업을 예약하고, 실제 실행 기록과 결과를 확인한다. 실행 위치, 시간대, 필요한 자료, 중지 방법을 설명할 수 있다.

### 다룰 기능

현재 대화의 후속 예약과 독립 예약의 차이, 실행 시각·시간대, 로컬 실행 조건, 스킬 지정, 실행 기록, 결과 알림, 수정·일시 중지·삭제.

로컬 파일을 사용하는 예약은 해당 컴퓨터와 앱이 실행 중이어야 한다. 웹의 예약이 컴퓨터의 폴더를 자동으로 읽는다고 설명하지 않는다. 이번 공통 실습은 3주차 로컬 프로젝트와 5주차 스킬을 사용한다. [예약 작업과 실행 조건](https://learn.chatgpt.com/docs/automations)

### 60분 진행

| 시간 | 강사 진행 | 수강생 행동 |
|---|---|---|
| 0~5분 | 스킬과 입력 폴더 상태 확인 | 예약할 작업을 한 문장으로 정리 |
| 5~12분 | 알림만 받는 예약과 실제 자료 처리 작업 비교 | 실행 위치·자료·시간대 확인 |
| 12~25분 | 같은 지시로 수동 실행한 뒤 시험 예약 등록 시연 | 수동 결과 확인 후 수업 중 1회 실행되도록 예약 |
| 25~40분 | 일정·저장 위치·미완료 처리 기준 수정 지원 | 작업 설정을 확인하고 실제 실행 기다리기 |
| 40~50분 | 실행 기록과 결과 파일 확인 시연 | 시험 실행 시각·상태·생성 파일 확인 |
| 50~60분 | 주간 반복 설정과 중지 방법 안내 | 시험 예약 정리, 개인 반복 일정 설정 또는 일시 중지 |

### 반복 예약 요청 예시

```text
이 로컬 실습 프로젝트에서 매주 월요일 오전 9시, 한국 시간 기준으로
‘주간 업무 정리’ 스킬을 실행하는 독립 예약 작업을 만들어줘.
입력은 ‘입력자료’ 폴더의 현재 자료야.
결과는 ‘결과물’ 폴더에 실행 날짜를 포함한 새 파일로 저장해줘.
필수 자료가 없거나 접근할 수 없으면 그 이유를 결과에 남겨줘.
자료에 없는 내용을 추측하지 말고, 외부 발송은 하지 마.
먼저 실행 위치, 일정, 사용할 스킬, 결과 저장 위치를 보여줘.
```

실습에서는 위의 반복 일정을 바로 장기간 유지하기보다 수업 중 시험 실행으로 먼저 확인한다. ‘지금 실행’은 작업 내용 확인에 사용하고, 예약 시각에 실제 시작했는지는 별도로 확인한다.

### 과제: 20~30분

컴퓨터를 사용할 수 있는 시간에 한 번 실제 예약 실행을 확인한다. 실행 시각, 사용한 입력, 결과 위치, 실패 시 이유를 기록한다. 불필요한 시험 예약은 중지하거나 삭제한다.

### 완료 기준

- 예약 목록의 등록 상태와 실제 실행 기록을 구분해 확인했다.
- 결과 파일을 열어 내용과 파일 이름을 확인했다.
- 한국 시간 기준의 일정을 확인했다.
- 작업을 수정하거나 중지할 수 있다.

### 강사 메모

다른 사람에게 메시지를 자동 발송하는 작업은 공통 예제로 사용하지 않는다. 파일 생성과 결과 확인으로 반복 실행의 원리를 익힌다. 자동 실행이 멈추면 입력 경로·컴퓨터 상태·앱 실행·권한·사용량을 차례로 확인한다.

이벤트 기반 자동 실행은 계정과 화면별 지원 범위가 다르므로 짧은 선택 소개로 둔다. 수업의 필수 과제는 시간 기반 예약 하나다.

## 12. 7주차 — 모바일에서 컴퓨터의 작업 이어가기

### 학습 목표

자신의 휴대폰을 컴퓨터에 연결하고, 같은 작업에 추가 지시를 보내 결과를 확인한다. 클라우드 대화 열기와 연결된 컴퓨터에서 작업하기를 구분한다.

### 다룰 기능

원격 연결 설정, 기기 페어링, 연결된 컴퓨터 선택, 기존 작업 이어가기, 추가 지시, 작업 상태·결과 확인, 연결 관리.

공식 안내상 원격 연결은 Windows·Mac 호스트와 iOS·Android에서 지원되며 제공 시점에 차이가 있을 수 있다. 최신 앱, 같은 계정·워크스페이스, 온라인 상태인 컴퓨터가 필요하다. 메뉴는 Codex 또는 Remote 등으로 보일 수 있다. [모바일 연결 준비](https://learn.chatgpt.com/docs/remote-connections)

### 60분 진행

| 시간 | 강사 진행 | 수강생 행동 |
|---|---|---|
| 0~5분 | 6주차 예약 결과와 모바일 로그인 확인 | 자신의 결과 파일 확인 |
| 5~12분 | 휴대폰·컴퓨터·클라우드의 역할 시연 | 작업을 실행할 컴퓨터 식별 |
| 12~25분 | 컴퓨터에서 연결을 시작하고 휴대폰을 페어링하는 과정 안내 | 자신의 기기 연결 |
| 25~40분 | 모바일에서 기존 작업을 여는 방법 지원 | 추가 메모를 보내고 업무 정리 실행 |
| 40~50분 | 후속 수정과 결과 확인 시연 | 휴대폰에서 수정 요청, 컴퓨터에서 생성 파일 확인 |
| 50~60분 | 연결 상태와 복구 방법 안내 | 연결 관리 화면 확인, 전원·절전·네트워크 조건 기록 |

### 모바일 요청 예시

```text
이 컴퓨터의 AI 실습 프로젝트에서 주간 업무 정리 스킬을 사용해줘.
기존 자료에 다음 메모를 추가해서 새 버전의 실행 계획을 만들어줘.
‘행사 안내문 검토 기한을 수요일 오후로 변경. 담당자는 아직 미정.’
입력 원본은 유지하고 결과물 폴더에 새 파일로 저장해줘.
바뀐 내용과 확인이 필요한 사항을 알려줘.
```

### 과제: 20~30분

컴퓨터를 켜두고 다른 장소에서 모바일로 작업 하나를 이어간다. 가능하면 모바일 데이터 등 다른 네트워크에서도 확인한다. 요청한 내용, 실제 실행된 컴퓨터, 생성된 결과 파일을 기록한다.

### 완료 기준

- 본인의 휴대폰과 컴퓨터를 연결했다.
- 모바일의 요청이 의도한 컴퓨터의 자료를 사용했는지 확인했다.
- 추가 지시로 결과를 수정하고 컴퓨터에 저장된 파일을 확인했다.
- 연결되지 않을 때 확인할 조건을 설명할 수 있다.

### 강사 메모

화면을 직접 조작하는 Computer Use와 파일 작업을 같은 것으로 설명하지 않는다. 공통 실습은 로컬 파일 작업으로 진행하고, 운영체제별 화면 조작은 지원되는 환경에서 선택 시연한다. 원격 기능이 제공되지 않은 계정에서는 강사 시연 후 개별 보완 항목으로 남긴다.

## 13. 8주차 — 내 업무를 하나의 반복 절차로 완성하기

### 학습 목표

수강생이 자기 업무에 필요한 도구만 골라 입력부터 결과 확인까지 연결한다. 기능을 모두 끼워 넣기보다 실제로 반복할 수 있는 절차를 완성한다.

### 권장 개인 과제

| 수강생 상황 | 권장 업무 | 입력과 결과 |
|---|---|---|
| 일반 직장인 | 주간 회의 후속 업무 | 회의 메모·진행표 → 실행 계획·보고 초안 |
| 자영업자 | 고객 요청 정리 | 가상화한 문의 메모 → 분류표·답변 초안 |
| 프리랜서 | 프로젝트 진행 보고 | 작업 기록 → 진행 보고·다음 할 일 |
| 일상 활용 | 모임·행사 준비 | 준비 메모 → 일정표·확인 사항·안내문 |

### 수업 전 준비

7주차 과제에 이어 자기 업무의 입력 자료 한 묶음과 원하는 결과 예시 하나를 가져온다. 이미 만든 지침·스킬을 재사용하고, 자료만 새것으로 바꿔도 된다.

### 60분 진행

| 시간 | 강사 진행 | 수강생 행동 |
|---|---|---|
| 0~5분 | 개인 과제의 범위 확인 | 오늘 완성할 업무를 한 문장으로 설명 |
| 5~10분 | 완료 기준 확인 | 입력·결과·실행 위치·검토 방법 결정 |
| 10~30분 | 개별 실습 지원 | 새 자료로 작업 실행, 결과 점검, 한 번 수정 |
| 30~50분 | 1인당 최대 2분 결과 공유 진행 | 입력 → 실행 → 결과 → 확인 방법 시연 |
| 50~60분 | 운영 안내와 보완 사항 정리 | 반복 사용할 절차와 다음 변경 사항 기록 |

10명 미만이면 공유 후 남는 시간을 개별 수정에 사용한다. 강사 도움을 받은 부분도 기록해 수료 후 보완할 대상을 분명히 한다.

### 종합 실습 요청 예시

```text
내가 반복하는 업무는 주간 회의 후속 정리야.
이번 입력 자료와 기존 프로젝트 지침, 주간 업무 정리 스킬을 사용해줘.
실행 전에 사용할 자료와 만들 결과물을 짧게 확인해줘.
결과를 만든 뒤 누락, 자료 간 충돌, 원문과 맞지 않는 수치가 있는지 검토해줘.
내가 다음 주에도 같은 작업을 실행할 수 있도록 필요한 입력과 실행 방법을 정리해줘.
내가 따로 요청하지 않은 기능이나 외부 발송은 추가하지 마.
```

### 최종 결과물

1. 직접 검토한 업무 결과물 한 세트
2. 계속 사용할 프로젝트 지침과 스킬
3. 사용할 경우 실행을 확인한 예약 작업과 모바일 연결
4. 한 페이지 분량의 ‘내 업무 실행 안내’

‘내 업무 실행 안내’에는 목적, 입력 자료 위치, 사용하는 지침·스킬·연결, 실행 요청, 결과 위치, 사람이 확인할 항목, 실패했을 때의 조치, 예약 중지 방법을 적는다.

### 과제: 20~30분

새로운 자료로 같은 절차를 한 번 더 실행한다. 이전 방식과 AI를 활용한 방식의 작업 시간을 대략 비교하고, 아직 사람이 해야 하는 일과 개선할 점을 기록한다.

### 완료 기준

- 자기 업무를 한 문장으로 설명할 수 있다.
- 지침·스킬·자료를 다시 찾을 수 있다.
- 서로 다른 입력으로 업무를 두 번 이상 수행했다.
- 결과에 대한 사람의 검토 단계를 수행했다.
- 실행 방법과 중지·복구 방법을 문서로 남겼다.

## 14. 공통 검토 기준과 과제 기록

### 매주 확인할 네 가지

| 항목 | 확인 질문 |
|---|---|
| 자료 | 내가 의도한 자료를 실제로 사용했는가? |
| 결과 | 요청한 형식과 필요한 내용을 갖췄는가? |
| 사실 | 날짜·담당자·수치·근거를 원문과 대조했는가? |
| 재사용 | 다음에도 실행할 지침과 파일 위치를 찾을 수 있는가? |

### 개인 적용 기록지

```text
이번 주 적용한 업무:
사용한 입력 자료:
실행한 앱과 작업 위치:
처음 요청:
수정 요청:
최종 결과 저장 위치:
내가 직접 확인한 내용:
막힌 부분과 해결 방법:
대략 걸린 시간:
다음에 바꿀 점:
```

과제 공유는 결과 한 장과 기록지를 기본으로 한다. 개인 업무 원본을 다른 수강생에게 공개하는 것을 과제 조건으로 삼지 않는다.

### 8주 종료 시 확인표

| 항목 | 완료 판단 |
|---|---|
| 업무 요청 | 자료·조건·결과 형식을 포함해 요청하고 수정 가능 |
| 개인화 | 프로젝트와 지침을 만들고 적용 여부 확인 |
| 파일 작업 | 로컬 입력·출력 위치와 원본 유지 여부 확인 |
| 플러그인 | 외부 서비스 하나를 실제 연결하고 자료 읽기 성공 |
| 스킬 | 개인 스킬 하나를 두 입력으로 검증 |
| 예약 | 실제 실행 기록과 결과를 확인하고 중지 가능 |
| 모바일 | 연결된 컴퓨터에서 작업하고 결과 확인 |
| 종합 | 업무 절차를 문서화하고 새로운 자료로 재현 |

기능 미제공이나 계정 문제로 직접 실행하지 못한 항목은 ‘보완 필요’로 기록한다. 강사 시연을 본 것과 본인이 실행한 것을 구분한다.

## 15. 추가 기능을 다루는 방식

핵심 실습이 일찍 끝난 수강생에게만 아래의 작은 확장 과제를 제공한다. 해당 기능을 추가한다고 공통 실습 완료 시간을 늘리지 않는다.

| 기능 | 배치 | 짧은 확장 과제 |
|---|---|---|
| 웹 검색·출처 확인 | 1주 | 결과에 필요한 외부 정보 하나를 공식 출처로 확인 |
| 이미지 입력 | 1주 또는 7주 | 메모 사진에서 할 일을 추출하고 원본과 비교 |
| 음성 입력·대화 | 1주 또는 7주 | 말로 후속 수정 요청하기. 화면과 계정 지원에 맞춰 시연 |
| 문서·표·발표 자료 생성 | 3~4주 | 완성한 실행 계획을 필요한 파일 형식 하나로 변환 |
| 이미지 생성 | 4주 | 안내문에 사용할 간단한 이미지를 만들고 사용 가능 여부 검토 |
| 브라우저·컴퓨터 조작 | 4주 | 읽기 중심의 웹 자료 수집 과정을 강사가 시연 |
| 작업 중 방향 수정 | 3주·8주 | 진행 중 추가 조건을 전달하고 최종 결과에 반영됐는지 확인 |
| 여러 작업 관리 | 8주 | 조사와 결과물 검토를 별도 대화로 나누어 정리 |
| Claude 비교 | 2주 또는 5주 | 동일한 업무 기준을 다른 앱에 옮기는 방법을 2~3분 소개 |

기능의 제공 여부와 도구 접근 범위를 확인한 뒤 시연한다. 브라우저 조작이나 파일 생성이 모든 화면에서 동일하게 작동한다고 안내하지 않는다. [현재 작업 기능 안내](https://learn.chatgpt.com/docs/use-chatgpt#what-chatgpt-work-can-do)

## 16. 9주차 이후로 이어가는 연결

8주차 종료 시 수강생은 자기 업무 자료와 지침을 정리하고, AI에게 파일 작업을 맡기고 결과를 검토하는 경험을 갖게 된다. 이를 바탕으로 9주차에 GitHub·Vercel 가입·연동과 공통 기본형 페이지 배포를 시작한다.

홈페이지에서는 같은 습관을 적용한다. 바꿀 내용을 구체적으로 요청하고, 변경 범위를 확인하고, 실제 화면을 검토한 뒤 배포한다. 앞 8주 안에서는 홈페이지 제작이나 GitHub·Vercel 가입을 필수 과제로 앞당기지 않는다.

## 17. 검토할 때 볼 지점

이 초안은 강사의 검토 후 주차별 실습량과 예제를 수정하기 위한 문서다. 다음 네 가지를 중심으로 검토하면 된다.

- 공통 업무 정리 예제가 실제 수강생의 직업과 관심에 맞는가?
- 각 주의 필수 실습 하나가 60분 안에 완성 가능한 범위인가?
- 지침 → 로컬 작업 → 연결 → 스킬 → 예약 → 모바일의 순서가 자연스러운가?
- 8주차에 수강생이 스스로 반복할 업무와 결과물이 남는가?

현재 문서는 강의 계획과 교재 제작 명세까지 포함한다. 실습 자료 파일, 강의 슬라이드, 계정별 기능 점검 결과는 별도 제작·확인 대상이다.

# 발표·이미지 스타일 참고 기준

가상의 참고 기준입니다. 실제 PowerPoint 템플릿이나 설치된 스킬이 아닙니다.

## 발표자료
- 크림색 배경, 짙은 남색 본문, 금색 또는 청록색 강조를 사용한다.
- 한 장에는 한 가지 주제와 짧은 설명을 넣는다.
- 표지, 개요, 설명, 예시, 마무리의 다섯 장으로 시작한다.
- 참고 예시의 이름·날짜·주장은 새 내용에 자동 복사하지 않는다.
- 완성한 파일을 열어 글자 넘침, 읽기 크기, 수정 가능 여부를 확인한다.

## 배너 이미지
- 가로 16:9 비율을 기준으로 한다.
- 제목 한 줄은 왼쪽, 단순한 그림은 오른쪽에 둔다.
- 문구가 실제로 정확하고 잘 보이는지 확인한다.
- 다음 이미지에도 쓸 색상·배치 기준을 문장으로 남긴다.
- 이미지 생성·내보내기 제공 여부는 실제 사용하는 계정에서 확인한다.

# 실습 프로젝트 지침 예시

이 파일은 수강생이 읽고 수정할 예시입니다. 필요한 내용만 검토한 뒤 자신의 실습 폴더에 AGENTS.md로 저장합니다.

- 이 프로젝트에서는 가상 모임의 자료를 정리한다.
- 작업 전에 사용할 입력 파일 목록을 확인한다.
- 입력자료의 원본은 수정하거나 삭제하지 않는다.
- 새 결과는 결과물 폴더에 저장하고 기존 파일을 덮어쓰지 않는다.
- 담당자, 날짜, 수치는 자료에 근거해 작성한다.
- 정보가 없거나 자료가 다르면 확인 필요로 표시하고 근거를 남긴다.
- 요청하지 않은 외부 발송, 공유, 앱 제작은 추가하지 않는다.
- 완료 후 사용한 파일, 결과 위치, 확인할 사항을 알려준다.
